# FactChecker（仮）- 偽りのニュースを検証せよ -

本プロジェクトは、プレイヤーが現代社会で必要とされる「メディアリテラシー」や「ファクトチェック能力」をゲームを通じて向上させることを目的とした、社会派ファクトチェックADVゲームの仕様書プロジェクトです。

---

## 1. ゲーム概要

「インターネット上の情報はすべて真実か？」

主人公の **レン（蓮）** は、ごく普通の高校2年生。ある日ネットで見たニュースに端を発し、幼馴染のしっかり者 **アオイ（葵）** とともに、ネット上やSNSに溢れる様々なフェイクニュースの真偽を確かめる検証活動に身を投じることになります。

### プレイヤーの「役に立つ」ポイント（スキル向上・知識増強）
1. **メディアリテラシーの向上**: 情報の発信元（ソース）を疑う、複数のソースを比較する（クロスチェック）習慣が身につきます。
2. **クリティカルシンキングの獲得**: 感情を煽る表現や、一見正しそうな統計データの罠、切り取り編集を見抜く力が養われます。
3. **実社会への応用**: 現実のフェイクニュースに類似した事例を扱うことで、日常生活でのデマ防止に役立ちます。

---

## 2. 主なゲームシステム（コアメカニクス）

1. **情報入手 & 吟味パート**
   - チャット、SNS投稿、インフルエンサーのブログなどから不審な情報（デマの種）を発見します。
2. **ゲーム内検索システム（ノーヒント設計）**
   - 画面内のテキストから怪しいと思う「単語」を自ら選んでクリックし、ゲーム内ブラウザで検索を実行して客観的な「証拠（ファクト）」を獲得します。
3. **証拠ボード（Evidence Board）**
   - 獲得した複数の証拠の相関関係（矛盾、裏付け、補足）を、付箋と色分けされたラインで視覚的に自動整理して表示します（検索中いつでも重ね合わせ表示で確認可能）。
4. **推理・矛盾指摘パート（アオイの柔らかいアシスト）**
   - 誤解している友人や、意図的にデマを流す相手の「矛盾した発言」を選択し、正しい「証拠付箋」を突きつけて論理的に説得します。間違えても、アオイが優しく進むべきヒントをアドバイスしてくれます。

---

## 3. シナリオ構成（全4章）

- **第1章：奇跡のダイエットフルーツ（チュートリアル）**
  - テーマ：ヘルスケアデマ。発信者の属性やドメイン（信頼性）の確認を学びます。
- **第2章：崩壊した化学工場（災害デマ）**
  - テーマ：災害パニック。画像の偽装、流用を見抜く逆画像検索を学びます。
- **第3章：現職市長の「失言」ビデオ（AIディープフェイク）**
  - テーマ：AI・高度な編集デマ。動画の切り取り、音声と口のズレ、前後の文脈検証を学びます。
- **第4章：偽情報（フェイク）の生産工場（総合・黒幕対決）**
  - テーマ：デマのビジネス構造。アフィリエイト広告収益を目的にデマを量産する「生産者（黒幕）」のサーバ情報・広告IDを暴き、情報社会の一員としての責任（安易に拡散しないこと）を自覚します。

---

## 4. プロジェクト構成（仕様書フォルダ：`/spec`）

ゲームの仕様は、以下のマークダウンファイルに分割されて詳細に定義されています。

- `/spec/`
  - `characters.md`: **登場キャラクター設定**。普通の高校生「レン」と、幼馴染「アオイ」の人物像、16ビットドット絵ビジュアルの方向性を定義。
  - `core_mechanics.md`: **コアメカニクス詳細**。検索から推理、アオイの柔らかい救済（アシスト）システムまでのロジックを定義。
  - `scenarios.md`: **シナリオ・ステージ構成**。全4章のストーリー、獲得する証拠、およびクリア後にプレイヤーが学ぶ実社会での防衛テクニックを定義。
  - `ui_layout.md`: **UIレイアウト・画面構成**。会話時と検索時の画面の切り替え、「証拠ボードを見る」ボタンによるオーバーレイ（重ね合わせ）表示の画面仕様を定義。
  - `developer_notes.md`: **開発者向け補足**。別のAIモデルやプログラマーが実装する際に発生する、データ構造や判定処理などの疑問点へのプログラミング方針。
