# ゲーム仕様書：UIレイアウト・画面構成

本ドキュメントでは、ファクトチェックADVゲーム「FactChecker（仮）」のユーザーインターフェース（UI）レイアウト、画面構成、および状態遷移について定義します。
中高生が迷わず、かつドット絵のレトロな雰囲気を最大限活かせるシンプルで洗練されたレイアウトを採用します。

---

## 1. 画面構成の基本ルール

ゲーム中は、現在進行しているフェーズ（状態）に応じて画面のレイアウトを明確に切り替えます。

### 1.1 会話・ストーリーパート（会話時）
シナリオの進行、導入、およびファクトチェック時のアオイによるナビゲーション時に表示される画面です。

- **レイアウト特徴**:
  - **キャラクターの立ち絵（スプライト）を表示**: 画面左右に、ドット絵で表現された「レン」や「アオイ」の爽やかで豊かな表情変化を伴う立ち絵を配置します。
  - **会話ウィンドウ（メッセージウィンドウ）**: 画面下部に透過またはドット絵フレーム付きのテキストエリアを配置し、等身大のテキスト（セリフ）を表示します。
  - **名前表示部**: 会話ウィンドウ上部に、現在喋っているキャラクターの名前を分かりやすく表示します。

### 1.2 検索・ブラウザパート（検索パート中）
プレイヤーがキーワードをクリックしてゲーム内のモックアップブラウザでファクトチェックを行う画面です。

- **レイアウト特徴**:
  - **検索画面のみを表示する（単一フォーカス）**:
    - **立ち絵や不要なUIは完全に非表示**にします。これにより、プレイヤーは実際のWeb検索やニュース読解をしているかのような高い没入感を得られます。
    - 画面全体にオリジナルのドット絵風ブラウザ（アドレスバー、検索窓、記事本文、検索結果リスト）が描画されます。
  - **常設ボタン「証拠ボードを見る」**:
    - 検索パート中、画面の右上または右下といった邪魔にならない位置に、視覚的に目立つ**「証拠ボードを見る（または証拠ボード）」ボタン**を常設します。
  - **訪問済みリンクのカラー変化**:
    - プレイヤーが「過去に訪れたページ」と「未読のページ」を瞬時に識別できるよう、すでにクリックして開いたことのあるWebページのタイトルリンクを**紫色**に変化させます。未読のページは爽やかな水色で表示され、これにより探索状況が直観的に把握可能となります。

## 2. 証拠ボードの閲覧・オーバーレイシステム

プレイヤーがいつでも手持ちのファクト（証拠付箋）や、それらの繋がりを確認できるようにするためのシステムです。

- **オーバーレイ表示（重ね合わせ表示と背景遮断）**:
  - プレイヤーが「証拠ボードを見る」ボタンを押すと、**現在の画面（ブラウザ画面や会話画面）の上に、灰色系の半透明フィルター（例：暗灰色に加えて彩度を下げるグレースケール処理やブラーを施した背景）を敷き、その上に重ね合わせ（オーバーレイモーダル）として証拠ボード画面を表示**します。
  - **背景の完全非活性化**: この灰色フィルター（バックドロップ）により、**ボードの裏にある画面（ブラウザや会話など）は視覚的にトーンダウンされ、同時に一切のクリックやタップ操作を受け付けない（触れられない）状態**になります。これにより、誤操作を完全に防止し、プレイヤーをボードの整理・確認に集中させます。
  - これにより、ゲームの進行度や、現在開いているブラウザのコンテキストを維持したまま、いつでも安全に脳内を整理することができます。
- **ボード内の要素**:
  - コルクボードの背景。
  - これまで獲得した「証拠カード（付箋）」。
  - 付箋同士を結ぶ「色分けされた関係性ライン（矛盾：赤、裏付け：緑、補足：青）」と「文字ラベル」。
- **閉じる（戻る）操作**:
  - ボード画面の隅に「閉じる（戻る）」ボタンを配置、またはボードの範囲外（暗幕部分）をクリックすることで、一瞬で元の画面（ブラウザまたは会話）に復帰します。

## 4. 開発者向け疑問・回答の統合

### 【AIが疑問に思うポイント】
> オーバーレイ中に裏画面の操作（ブラウザのリンクをクリックするなど）は可能か？

- **決定仕様**:
  - **不可能（灰色フィルターによる完全遮断）**: 証拠ボードが開いている間、裏の画面（ブラウザや会話など）には全体を覆う灰色系の半透明カバーレイヤーが被せられます（CSSの `backdrop-filter: grayscale(100%) opacity(50%)` やそれに類するスタイリングを推奨）。
  - このカバーレイヤーがすべてのマウス/タッチ入力をブロック（キャッチ）するため、裏画面の操作は**物理的に完全に不可能です。**
  - 有効な操作は、オーバーレイ最前面にある証拠ボード上の要素（付箋のズーム、ピンの確認、ボードを閉じるためのボタン、またはボード外の灰色フィルター領域をクリックして閉じる挙動）のみに限定されます。
